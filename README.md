#  Flex Turismo

> Projeto desenvolvido como parte dos desafios e cursos de capacitação em desenvolvimento Front-end da Digital Innovation One (DIO). O **Flex Turismo** é uma plataforma web moderna e responsiva voltada para o setor de turismo, destacando destinos, pacotes de viagens e uma interface interativa para os usuários.

---

##  Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias e conceitos:

* **HTML5:** Estruturação semântica das páginas web.
* **CSS3:** Estilização avançada, utilizando recursos modernos de layout.
* **Flexbox:** Alinhamento e distribuição flexível de elementos para garantir responsividade.
* **Git & GitHub:** Controle de versionamento de código e hospedagem do repositório.

---

##  Funcionalidades

*  **Layout Responsivo:** Adaptado para diferentes tamanhos de tela (desktop, tablets e smartphones).
*  **Design Moderno:** Estilização limpa focada na experiência do usuário (UX).
*  **Navegação Intuitiva:** Seções bem estruturadas para apresentação de destinos turísticos.
